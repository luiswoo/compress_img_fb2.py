# Настройки цветности и выбора формата

Этот документ дополняет `README.md` и описывает параметры, которые влияют на определение цветности изображений, выбор формата и квантование.

## Общий принцип работы

Скрипт делит изображения на группы и обрабатывает их по-разному.

| Группа | Куда сохраняется | Основные параметры |
|---|---|---|
| Цветные изображения | JPEG или палитрный PNG; выбирается вариант с меньшим размером | `quality`, `colors`, `colors_quantize` |
| Монохромные изображения с прозрачностью | PNG с альфа-каналом | `mono_quantize`, `mono_colors` |
| Монохромные изображения без прозрачности | Как цветные: авто-выбор JPEG/PNG или только JPEG | `quality`, `colors` |

Упрощённый алгоритм:

1. Изображение масштабируется по параметрам `max_size` и `min_size`.
2. Для PNG скрипт определяет, является ли изображение цветным или монохромным.
3. Если изображение цветное:
   - при заданном `colors` скрипт оценивает потенциальный размер палитрного PNG и JPEG и выбирает меньший файл;
   - если `colors = None` или указано `-c 0`, используется только JPEG.
4. Если изображение монохромное и содержит прозрачность:
   - оно сохраняется как PNG с альфа-каналом;
   - режим обработки зависит от `mono_quantize`.
5. Если изображение монохромное, но прозрачности нет:
   - оно обрабатывается как цветное.

## Цветовые параметры командной строки

| Параметр | По умолчанию | Диапазон | Назначение |
|---|---:|---|---|
| `-q`, `--quality` | `85` | `1-100` | Качество сжатия JPEG и WebP |
| `-c`, `--colors` | `128` | `0-256` | Число цветов для палитры цветных изображений. `0` — только JPEG |
| `--colors_quantize` | `"LIBIMAGEQUANT"` | `FASTOCTREE`, `LIBIMAGEQUANT`, `MEDIANCUT` | Метод обработки цветных png без прозрачности |
| `--tolerance` | `15` | `0-255` | Порог определения цветности |
| `--sample-size` | `5000` | положительное число | Количество пикселей для проверки цветности |
| `--mono-quantize` | `"LA"` | `LA`, `FASTOCTREE`, `LIBIMAGEQUANT`, `MEDIANCUT` | Метод обработки монохромных изображений с прозрачностью |
| `--mono-colors` | `32` | `2-256` | Число цветов палитры монохромных изображений, если `mono_quantize != "LA"` |

> В режиме `--webp` параметры `--colors`, `--tolerance`, `--sample-size`, `--mono-quantize`, `--mono-colors` не используются.

## `quality`

Качество сжатия для JPEG и WebP.

- `1` — максимальное сжатие, минимальный размер.
- `85` — сбалансированное значение по умолчанию.
- `100` — максимальное качество, больший размер файла.

Для типичных иллюстраций часто подходят значения `70-90`.

Для аниме-подобных изображений без градиентов можно пробовать более низкие значения, например `60`:

```bash
python compress_img_fb2.py -q 60 -c 64 book.fb2
```

## `colors`

Число цветов для палитры PNG, когда скрипт выбирает между палитрным PNG и JPEG.

Допустимые значения:

- `1-256` — использовать палитрный PNG и сравнивать его с JPEG.
- `0` в командной строке — не использовать PNG для цветных изображений, только JPEG.
- `None` в `CONFIG` — то же самое, что `-c 0`.

Практическая рекомендация:

| Значение | Когда использовать |
|---:|---|
| `64` | Сильное сжатие, иллюстрации с малым числом цветов |
| `96-128` | Универсальный компромисс |
| `192-256` | Нужно больше деталей, но файл может стать крупнее |

Для фотографий и изображений с градиентами обычно выигрывает JPEG.

Для изображений с плоскими цветами, контурами, схемами или аниме-стилем иногда выигрывает палитрный PNG.

## `tolerance`

Порог определения цветности.

Изображение считается цветным, если хотя бы у одного проверенного пикселя выполняется одно из условий:

```text
abs(R - G) > tolerance
abs(R - B) > tolerance
abs(G - B) > tolerance
```

Для честного серого изображения обычно выполняется:

```text
R = G = B
```

Поэтому оно определяется как монохромное.

### Зачем нужен `tolerance`

Серое изображение, которое ранее было сохранено как JPEG, может получить цветовой шум. Например, вместо нейтрального тёмного пикселя могут быть значения:

```text
R = 12, G = 10, B = 8
```

При слишком низком `tolerance` такое изображение будет ошибочно признано цветным. Это может привести к потере прозрачности или неоптимальному сжатию.

### Рекомендуемые значения

| Источник изображений | `tolerance` |
|---|---:|
| Чистые PNG, рендеры, схемы | `3-5` |
| Смешанный архив, возможны JPEG | `12-15` |
| Сканы с лёгким тонированием, которые нужно сохранить цветными | `8-10` |

Значение по умолчанию `15` подходит для большинства смешанных архивов и ч/б изображений с JPEG-шумом.

## `sample_size`

Сколько пикселей проверяется для определения цветности.

- По умолчанию `5000`.
- Для большинства иллюстраций этого достаточно.
- Если изображение содержит мало цветных деталей, но их важно заметить, можно увеличить до `20000`.

Большее значение повышает точность, но немного замедляет обработку.

Пример:

```bash
python compress_img_fb2.py book.fb2 --sample-size 20000
```

## `mono_quantize`

Метод обработки монохромных изображений с прозрачностью.

| Значение | Описание | Когда использовать |
|---|---|---|
| `LA` | Grayscale + альфа-канал, сохраняются градации серого и прозрачность | Качество важнее размера; градиенты, тени, сканы |
| `FASTOCTREE` | Палитризация, быстрый метод | Хороший баланс размера и качества; обычно доступен |
| `LIBIMAGEQUANT` | Палитризация с более качественным квантованием | Если библиотека доступна в установленном Pillow |
| `MEDIANCUT` | Палитризация методом median cut | В основном для изображений без прозрачности; для RGBA возможен fallback |

Режим по умолчанию: `LA`.

Если нужно уменьшить размер монохромных изображений, используйте:

```bash
--mono-quantize FASTOCTREE --mono-colors 128
```

## `mono_colors`

Число цветов в палитре для монохромных изображений с прозрачностью.

Параметр важен только если `mono_quantize` не равен `LA`.

Для `LA` палитра не используется.

| Значение | Эффект |
|---:|---|
| `32` | Максимальная экономия; на градиентах может быть заметен бандинг |
| `128` | Хороший компромисс; бандинг обычно почти незаметен |
| `256` | Максимальное качество; файл может быть заметно больше |

Диапазон: `2-256`.

## Готовые рецепты

### 1. Книга с ч/б иллюстрациями и градациями серого

Максимальное качество монохромных изображений:

```bash
python compress_img_fb2.py book.fb2 --tolerance 15 --mono-quantize LA
```

### 2. То же, но компактнее

```bash
python compress_img_fb2.py book.fb2 \
    --tolerance 15 \
    --mono-quantize FASTOCTREE \
    --mono-colors 128
```

### 3. Смешанная книга: цветные обложки и серые рисунки

```bash
python compress_img_fb2.py book.fb2 \
    --tolerance 15 \
    -q 85 \
    -c 128 \
    --mono-quantize FASTOCTREE \
    --mono-colors 128
```

### 4. Максимальное сжатие цветных, минимальная палитра для серых

```bash
python compress_img_fb2.py book.fb2 \
    -q 60 \
    -c 96 \
    --tolerance 15 \
    --mono-quantize FASTOCTREE \
    --mono-colors 32
```

### 5. Обработка библиотеки целиком

> Оригинальные файлы будут заменены.

```bash
python compress_img_fb2.py ./library \
    --tolerance 15 \
    --mono-quantize LA
```

### 6. Крупнее изображения, монохромные без палитризации

```bash
python compress_img_fb2.py book.fb2 \
    --max-size 1200 \
    --min-size 900 \
    --tolerance 15 \
    --mono-quantize LA
```

## Частые вопросы

### Почему серая картинка попала в JPEG на белом фоне?

Скорее всего, `tolerance` слишком низкий.

Из-за шума после JPEG или цветных контуров сглаживания изображение было определено как цветное.

Попробуйте поднять `tolerance` до `12-15`:

```bash
python compress_img_fb2.py book.fb2 --tolerance 15
```

### `LA` даёт большие файлы, что делать?

Используйте палитризацию для монохромных изображений:

```bash
python compress_img_fb2.py book.fb2 \
    --mono-quantize FASTOCTREE \
    --mono-colors 128
```

В большинстве случаев бандинг почти незаметен, а размер файла становится меньше.

### Как понять, что картинка классифицирована правильно?

Смотрите вывод скрипта. Для каждого изображения обычно печатается, определено оно как цветное или монохромное, а также итоговый формат.

### `-c 0` и `--mono-colors 0` — это одно и то же?

Нет.

| Параметр | Назначение |
|---|---|
| `-c`, `--colors` | Управляет палитрой для цветных изображений. `0` — только JPEG |
| `--mono-colors` | Управляет палитрой монохромных изображений с прозрачностью. Диапазон обычно `2-256` |

### Что делать, если цветные детали не замечаются?

Увеличьте `--sample-size`:

```bash
python compress_img_fb2.py book.fb2 --sample-size 20000
```

Это полезно, если цветные контуры, подписи или мелкие детали не попадают в случайную выборку пикселей.
