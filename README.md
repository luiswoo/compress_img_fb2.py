# compress_img_fb2.py

Скрипт сжимает и масштабирует изображения в FB2-файлах.

## Основные возможности

- Масштабирование изображений по заданным размерам большей и меньшей сторон.
- Сжатие изображений в JPEG, WebP с заданным в % качеством.
- Сохранение монохромных и близких к серому изображений с прозрачностью в PNG с альфаканалом.
- Для полноцветных изображений сравнивает размер JPEG и PNG (без альфаканала) и выбирает меньший.
- Пропуск в обработке маленьких изображений, всех PNG или только монохромных прозрачных PNG.
- Может конвертировать все изображения в WebP (не соответствует спецификации FB2).

## Размер и качество по умолчанию

По умолчанию используются значения:

- `max_size = 800` — максимальный размер большей стороны, пиксели.
- `min_size = 600` — целевой размер меньшей стороны, пиксели.
- `quality = 85` — качество сжатия JPEG/WebP, от 1 до 100.

Значения `800 × 600` соответствуют максимальному разрешению по спецификации FB2.

Если изображение квадратное, масштабирование выполняется по параметру `min_size`.

> Скрипт не проверяет корректность экстремальных комбинаций размеров, например `--max-size 800 --min-size 1`.

## Использование

### Обработка одного файла

```bash
python compress_img_fb2.py "/путь/до/файла/файл.fb2"
```

В каталоге с исходным файлом создаётся выходной файл вида:

```text
compress_файл.fb2
```

Оригинальный файл не изменяется.

### Рекурсивная обработка каталога

```bash
python compress_img_fb2.py "/путь/до/каталога"
```

Скрипт найдёт все файлы `.fb2` в указанном каталоге и подкаталогах и обработает их.

> Внимание: в этом режиме оригинальные файлы заменяются. Перед обработкой большой библиотеки рекомендуется сделать резервную копию.

## Примеры

```bash
# Обработать один файл настройками по умолчанию
python compress_img_fb2.py "/путь/до/файла/файл.fb2"

# Более сильное сжатие, 60% качество и 64 цвета для PNG
python compress_img_fb2.py -q 60 -c 64 "/путь/до/файла/файл.fb2"

# Пропускать изображения, площадь которых меньше 10% от области 800×600
python compress_img_fb2.py --skip small=10 "/путь/до/файла/файл.fb2"

# Пропускать все PNG, кроме обложки
python compress_img_fb2.py --skip png "/путь/до/файла/файл.fb2"

# Конвертировать все изображения в WebP
python compress_img_fb2.py --webp "/путь/до/каталога"
```

## Параметры командной строки

Если параметр не указан, используется значение из блока `CONFIG` внутри скрипта.

| Параметр | Назначение |
|---|---|
| `path` | Путь до `.fb2` файла или каталога с `.fb2` файлами |
| `-q`, `--quality N` | Качество сжатия JPEG/WebP, `1-100` |
| `-c`, `--colors N` | Число цветов для палитры PNG при авто-выборе, `1-256`. `0` — только JPEG |
| `--webp` | Конвертировать все изображения в WebP |
| `--skip RULE` | Правило пропуска изображений: `small[=N]`, `png`, `png_mono_alpha` |
| `--max-size N` | Максимальный размер большей стороны, пиксели |
| `--min-size N` | Целевой размер меньшей стороны, пиксели |
| `--tolerance N` | Порог определения цветности, `0-255` |
| `--sample-size N` | Количество пикселей для проверки цветности |
| `--mono-quantize M` | Метод обработки монохромных изображений с прозрачностью |
| `--mono-colors N` | Число цветов палитры монохромных изображений, `2-256` |

## Исключение изображений из обработки: `--skip`

Параметр `--skip` принимает одно правило за раз. Значение можно указывать через `=` или `:`.

| Правило | Действие | Особенности |
|---|---|---|
| `small[=N]` | Пропускать изображения, площадь которых меньше `N%` от площади области `max_size × min_size` | По умолчанию `N = 10` |
| `png` | Пропускать все изображения с расширением PNG | Обложка `cover.*` всё равно обрабатывается |
| `png_mono_alpha` | Пропускать только монохромные PNG с альфа-каналом | Обложка `cover.*` всё равно обрабатывается; цветные PNG обрабатываются обычным способом |

Формула для `small`:

```text
width * height < max_size * min_size * N / 100
```

Примеры:

```bash
python compress_img_fb2.py --skip small book.fb2
python compress_img_fb2.py --skip small=10 book.fb2
python compress_img_fb2.py --skip small:10 book.fb2
python compress_img_fb2.py --skip png book.fb2
python compress_img_fb2.py --skip=png book.fb2
python compress_img_fb2.py --skip png_mono_alpha book.fb2
```

Правила `--skip` действуют и в режиме `--webp`. Пропущенное изображение остаётся в исходном формате и размере.

## Режим WebP

```bash
python compress_img_fb2.py --webp "/путь/до/каталога"
```

> Формат WebP не соответствует спецификации FB2. Используйте его только если читалка поддерживает WebP.

Особенности режима:

- Все изображения конвертируются строго в WebP.
- Авто-выбор между PNG и JPEG не выполняется.
- Прозрачность сохраняется альфа-каналом, без заливки фоном.
- Доступны параметры качества и размера сторон: `-q/--quality`, `--max-size`, `--min-size`.
- Также действует параметр `--skip`.
- Не используются параметры цветности и палитры: `-c/--colors`, `--mono-quantize`, `--mono-colors`, `--tolerance`, `--sample-size`.

Примеры:

```bash
python compress_img_fb2.py --webp book.fb2
python compress_img_fb2.py --webp -q 60 book.fb2
```

## Настройки внутри файла

В начале скрипта находится блок `CONFIG`. Значения по умолчанию:

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `max_size` | `800` | Максимальный размер большей стороны, пиксели |
| `min_size` | `600` | Целевой размер меньшей стороны, пиксели |
| `quality` | `85` | Качество сжатия JPEG/WebP, `1-100` |
| `colors` | `128` | Число цветов для палитры PNG при авто-выборе. `None` — только JPEG |
| `mono_quantize` | `"LA"` | Метод обработки монохромных изображений с прозрачностью |
| `mono_colors` | `32` | Число цветов палитры монохромных изображений, если `mono_quantize != "LA"` |
| `tolerance` | `15` | Порог определения цветности, `0-255` |
| `sample_size` | `5000` | Количество пикселей для проверки цветности |
| `webp` | `False` | Если `True`, все изображения конвертируются в WebP |
| `skip` | `[]` | Правила пропуска изображений |
| `small_percent` | `10` | Порог для правила `small`, проценты |

Параметры командной строки переопределяют значения `CONFIG`.
