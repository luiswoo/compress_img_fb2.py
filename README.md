Сжимает и мастабирует изображения в fb2 файле. По умолчанию наибольшая сторона изображения 800 пикселей, наименьшая 600 пикслей (Если изображение равностороннее (квадратное), то масштабирование будет по меньшей стороне (min_size)). Степень сжатия 85%. За это соотвественно отвечают: max_size, min_size, quality в настройках обработки.  
Пытается определить в png черно-белые и малоцветные изображения и конвертирует их в png, всё остальное конвертируется в jpg. За определение цветности отвечают параметры tolerance и sample_size.

Использование: 
1. обработка одного файла -- python compress_img_fb2.py "/путь_до_файла/файл.fb2" -- создаёт в каталоге с исходным файлом, выходной файл с припиской comress_файл.fb2.
2. рекурсивная обработка всех fb2 файлов в каталоге с заменой оригинала -- python compress_img_fb2.py "/путь_до_каталога".
