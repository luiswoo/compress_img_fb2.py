Скрипт сжимает и мастабирует изображения в fb2 файле. По умолчанию наибольшая сторона изображения 800 пикселей, наименьшая 600 пикслей (это максимальное разрещение по спицификации fb2; если изображение равностороннее (квадратное), то масштабирование будет по меньшей стороне (min_size); защиты от не пропорциональны параметров разрешения, как 800x1 не предусмотрено). По умолчанию степень сжатия 85%. За эти настройки соотвественно отвечают: max_size, min_size, quality в настройках внутри файла, либо предопределяются внешними параметрами.  
Скрипт пытается определить в png монохромные изображения с альфа-каналом и конвертирует их в png; либо конвертируется в jpg или в png (при наличии зачения (1-256) у параметра colors для png), если изображение определено полноцвентным -- скрипт сравнивает потенциальный размер файла в обоих форматах перед сжатием и выбирает наименший; либо только jpg, если в настройка указано значение None у параметра colors. За определение цветности png отвечают параметры tolerance и sample_size (по умолчанию настроено на ч\б изображения).

Использование: 
1. Обработка одного файла -- python compress_img_fb2.py "/путь_до_файла/файл.fb2" -- создаёт в каталоге с исходным файлом, выходной файл с припиской comress_файл.fb2.
2. Рекурсивная обработка всех fb2 файлов в каталоге с заменой оригинала -- python compress_img_fb2.py "/путь_до_каталога".
3. Предопределяющие внешние параметры: -c N (количество цветов для PNG, для автовыбра по размеру между png и jpg -- указывать для потенциальной подмены менее 64 и более 128 цветов смысла особого нет); -q N -- степпень сжатия изображения. python compress_img_fb2.py -q 60 -c 64 "/путь_до_файла/файл.fb2" -- для обработки аниме образных картинок без градиетнов (в более 90% случаев выбирается jpg).
4. Исключение изображений из обработки через внешний параметр --skip small (--skip small=10 т.е. 10% -- это значение установлено по умолчанию в настройках), если его площадь меньше n от площади большей и меньшей стороны (max_size * min_size), с любым расширением, если это jpg или png; пропуск изображений с расширением png через внешние параметры --skip=png и --skip=png_mono_alpha для тех png, что были определены как монохромные с альфа каналось; в обоих случаях пропускается всё, кроме обложки cover.*.
5. Конвертация всех изображений в webp (данный формат не соотвествует спецификации fb2) -- python compress_img_fb2.py --webp "/путь_до_каталога" При конвертации в webp доступны только параметры качества и размер сторон
