Сжимает и мастабирует изображения в fb2 файле. По умолчанию наибольшая сторона изображения 800 пикселей, наименьшая 600 пикслей (Если изображение равностороннее (квадратное), то масштабирование будет по меньшей стороне (min_size)). Степень сжатия 75%. За это соотвественно отвечают: max_size, min_size, quality в настройках обработки.  
Пытается определить в png монохромные изображения с альфа-каналом и конвертирует их в png с потерями, всё остальное конвертируется в jpg (или в png, если оно при сравнении окажется легче (скрипт сравнивает потенциальный размер файла в обоих форматах перед сжатием)). За определение цветности отвечают параметры tolerance и sample_size (по умолчанию настроено на ч\б изображения).

Использование: 
1. обработка одного файла -- python compress_img_fb2.py "/путь_до_файла/файл.fb2" -- создаёт в каталоге с исходным файлом, выходной файл с припиской comress_файл.fb2.
2. рекурсивная обработка всех fb2 файлов в каталоге с заменой оригинала -- python compress_img_fb2.py "/путь_до_каталога".
3. предопределяющие внешние параметры: -c N (количество цветов для PNG, для автовыбра по размеру между png и jpg -- указывать для потенциальной подмены менее 64 и более 128 цветов смысла особого нет); -q N -- степпень сжатия изображения. python compress_img_fb2.py -q 60 -c 64 "/путь_до_файла/файл.fb2" -- для обработки аниме образных картинок без градиетнов (в более 90% случаев выбирается jpg).
