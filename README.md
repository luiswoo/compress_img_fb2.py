Сжимает и мастабирует изображения в fb2 файле. По умолчанию наибольшая сторона изображения 800 пикселей, наименьшая 600 пикслей (Если изображение равностороннее (квадратное), то масштабирование будет по меньшей стороне (min_size)). Степень сжатия 75%. За это соотвественно отвечают: max_size, min_size, quality в настройках обработки.  
Пытается определить в png монохромные изображения с альфа-каналом и конвертирует их в png с потерями, всё остальное конвертируется в jpg (или в png, если оно при сравнении окажется легче, но это редкость на практике). За определение цветности отвечают параметры tolerance и sample_size (по умолчанию настроено на ч\б изображения).

Использование: 
1. обработка одного файла -- python compress_img_fb2.py "/путь_до_файла/файл.fb2" -- создаёт в каталоге с исходным файлом, выходной файл с припиской comress_файл.fb2.
2. рекурсивная обработка всех fb2 файлов в каталоге с заменой оригинала -- python compress_img_fb2.py "/путь_до_каталога".
3. предопределяющие внешние параметры: -c N (количество цветов для PNG, для автовыбра по размеру между png и jpg -- менее 64 и более 128 цветов смысла особого нет); -q N -- степпень сжатия изображения. python compress_img_fb2.py -q 60 -c 64 "/путь_до_файла/файл.fb2" -- для обработки аниобразных картинок без градиетнов.





 ==================== НАСТРОЙКИ ОБРАБОТКИ ====================
 quality: качество JPEG (1-100). Переопределяется флагом -q / --quality
 colors: количество цветов для PNG авто-выбора (1-256).
         None — только JPEG, без авто-выбора.
 mono_quantize: метод для монохромных изображений с прозрачностью.
                "LIBIMAGEQUANT" — лучшее качество, требует поддержки Pillow
                "FASTOCTREE" — всегда доступен, быстрый
                "MEDIANCUT" — только для непрозрачных (RGBA автоматически fallback)
                "LA" — grayscale+alpha PNG, без квантования, максимальное качество
 mono_colors: сколько цветов оставлять при квантовании монохромных.
 max_size: максимальный размер по длинной стороне (px)
 min_size: минимальный размер по короткой стороне (px)
 tolerance: порог определения цветности (разница RGB)
 sample_size: сколько пикселей проверять для определения цветности
